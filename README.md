1. Introduction:
   Hangman is a word-guessing game developed using Python. The player must guess a hidden word by entering one letter at a time. The game continues until the player guesses the word correctly or reaches the maximum number of incorrect guesses.
   
3. Aim:
   To develop an interactive word-guessing game using Python programming concepts such as loops, conditional statements, lists, strings, and random module.
   
5. Objective:
   1. To create a simple interactive game.
   2. To understand Python control flow.
   3. To implement logical decision-making.
   4. To practice handling user input.
   5. To improve programming and problem-solving skills.
      
6. Technologies Used:
   1. Programming Language: Python
   2. IDE: VS Code / Python IDLE
   3. Module: Random
   
7. Game Rules:
   1. A random word is selected from a predefined list.
   2. The word is hidden using underscores.
   3. The player guesses one letter at a time.
   4. Correct guesses reveal the letter.
   5. Incorrect guesses reduce the remaining chances.
   5. The player gets a maximum of 6 incorrect guesses.
   6. The game ends when the word is guessed or the attempts are exhausted.
      
8. Algorithm:
   Step1: Start the program.
   Step2: Import the random module.
   Step3: Create a list of words.
   Step4: Select a random word.
   Step5: Hide all letters using underscores.
   Step6: Ask the player to enter a letter.
   Step7: Check whether the letter is in the word.
   Step8: Update the displayed word or incorrect guess count.
   Step9: Repeat until the player wins or loses.
   Step10: Display the result.
   Step11: Stop the program.
   
10. Features:
   1. Random word selection.
   2. Interactive letter guessing.
   3. Maximum of 6 incorrect attempts.
   4. Displays guessed letters.
   5. Detects win and loss conditions.
   6. Simple text-based interface.
